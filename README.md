# Saravanan Fitness Coaching Portfolio

Premium, responsive fitness-coaching portfolio built with Vite, HTML, CSS and vanilla JavaScript.

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Add Saravanan's fitness photos

Put six images in:

`assets/gallery/`

Use these filenames:

- `photo-01.jpg`
- `photo-02.jpg`
- `photo-03.jpg`
- `photo-04.jpg`
- `photo-05.jpg`
- `photo-06.jpg`

If you prefer PNG/WebP, change the image extension in `src/main.js`.

## Add the workout video

Put the video at:

`assets/video/saravanan-workout.mp4`

Recommended format: MP4 / H.264.

You do **not** need to change the HTML after adding that exact file. The video section is already wired to it and the placeholder disappears when the browser loads the video.

## Current design direction

- Obsidian / graphite background
- Electric lime primary accent
- Small red secondary accent
- Animated particle field with connecting lines
- Mouse-reactive 3D parallax hero
- Rotating wireframe sphere and orbital rings
- 3D tilt cards
- Scroll reveal animation
- Fitness photo editorial gallery
- Workout video showcase
- Coaching pricing with 1 / 3 / 6 / 12 month toggle
- Transformation placeholders
- Dashboard preview
- Testimonials placeholders
- Coach profile
- FAQ accordion
- Responsive mobile navigation

## Content placeholders

The transformation, testimonial and FAQ areas intentionally contain placeholders because real client names, claims and policies should be supplied by Saravanan rather than invented.
